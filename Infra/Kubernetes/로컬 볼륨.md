# 로컬 볼륨 : hostPath, emptyDir

- `hostPath`는 호스트와의 볼륨 공유를 위해, `emptyDir`은 파드 컨테이너 간 볼륨 공유를 위해 사용됨
- 두 볼륨은 자주 사용되는 볼륨 방식은 아님

### hostPath

```yaml
apiVersion: v1                         
kind: Pod
metadata:
  name: hostpath-pod
spec:
  containers:
    - name: my-container
      image: busybox
      args: ["tail", "-f", "/dev/null"]
      volumeMounts:
        - name: my-hostpath-volume
          mountPath: /etc/data
  volumes:
    - name: my-hostpath-volume
      hostPath:
        path: /tmp
```

- `hostPath` 방식의 경우 파드가 다른 노드로 옮겨간 경우 이전 노드에 저장된 데이터에 접근할 수 없음
	- 스케줄링으로 특정 노드에 파드를 둬도 되겠지만 호스트 서버의 장애 발생 시 데이터가 손실됨
- 만약 파드 자체가 현재 워커 노드에 대한 정보를 직접 읽어야 하는 경우에는 해당 옵션이 적합할 수 있음

### emptyDir

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: emptydir-pod
spec:
  containers:
  - name: content-creator
    ...
    volumeMounts:
    - name: my-emptydir-volume               # apache-webserver와 볼륨을 공유함
      mountPath: /data
  - name: apache-webserver
    ...
    volumeMounts:
    - name: my-emptydir-volume
      mountPath: /usr/local/apache2/htdocs/  # content-creator와 볼륨을 공유함

volumes:
  - name: my-emptydir-volume
    emptyDir: {}
```

- 데이터를 영속적으로 보존하기 위함이 아닌, 파드 실행 중에만 필요한 임시 저장 공간을 생성함
	- `emptyDir` 이름처럼 비어있는 상태로 생성되고, 파드 삭제 시에 같이 삭제됨
- `emptyDir`은 한 컨테이너가 파일을 관리하고 다른 컨테이너가 이를 사용하는 경우에 유용하게 사용됨
