# 인그레스

- 인그레스는 외부로부터의 요청을 어떻게 처리할 것인지 네트워크 7계층 레벨에서 정의하는 오브젝트임
- 인그레스 오브젝트가 담당할 수 있는 기본적인 기능은 다음과 같음
	- 외부 요청 라우팅 : 특정 경로로 들어온 요청을 특정 서비스로 전달할지 정의
	- 가상 호스트 기반 요청 처리 : 도메인은 다르지만 서버 IP는 동일한 경우 어떻게 처리할지 정의
	- SSL/TLS 보안 연결 처리 : 여러 개의 서비스로 요청을 라우팅할 때 인증서 적용

### 인그레스의 구조

```
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: ingress-example
  annotations:
    nginx.ingress.kubernetes.io/rewrite-target: /
spec:
  ingressClassName: nginx
  rules:
  - host: alicek106.example.com
    http:
      paths:
      - path: /echo-hostname
        pathType: Prefix
        backend:
          service:
            name: hostname-service
            port:
              number: 80
```

- `host` : 해당 도메인 이름으로 접근하는 요청에 대해서 처리 규칙을 적용함 (여러 도메인 설정 가능)
- `path` : 해당 경로에 들어온 요청을 어느 서비스로 전달할 것인지를 정의함 (위 예시에서는 /echo-hostname 경로의 요청을 backend 서비스에 전달함)
- `name, port` : `path`로 들어온 요청이 전달될 서비스와 포트임

- 인그레스는 요청을 처리하는 규칙을 정의하는 오브젝트일 뿐, 실제 외부 요청을 받는 실제 서버가 아님
- 외부 요청은 인그레스 컨트롤러가 받으며, 인그레스는 반드시 인그레스 컨트롤러 서버와 함께 사용해야 함
	- 대표적으로 Nginx 웹 서버 인그레스 컨트롤러를 주로 사용함
