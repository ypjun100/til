# OSI(Open Systems Interconnection) 7계층

- OSI 7계층은 네트워크 통신 과정을 역할에 따라 7단계로 나눈 개념 모델로, 각 계층을 레이러로 부름
- 현대에 많이 사용되는 TCP/IP 모델의 경우에는 인터넷에서 사용하는 프로토콜 체계를 모델화한 형태임
	- OSI는 다양한 통신 시스템을 공통된 틀로 설명하기 위함이고, TCP/IP는 인터넷 프로토콜의 구조를 설명하기 위함이라 두 모델 간의 타깃이 다름
- 데이터를 보낼 때는 7계층 -> 1계층으로 캡슐화를 하고, 받을 때는 1계층 -> 7계층으로 역캡슐화를 진행함

### 7계층 - 응용 계층

- 응용 프로그램이 네트워크 서비스를 이용할 수 있도록 통신 규칙을 제공하는 계층임
- 어떤 요청과 응답을 주고받을지 정의하여, 웹페이지 요청, 이메일 전송 같은 서비스를 제공함
- 응용 계층의 대표적인 프로토콜로는 `HTTP`, `DNS`, `SMTP`, `SSH` 등이 있음

### 6계층 - 표현 계층

- 문자나 숫자 등을 어떤 바이트 표현으로 주고받을지 송신자와 수신자 간 데이터 표현 방식을 맞추는 계층임
- 송수신 데이터의 일관성 뿐만 아니라 압축/해제, 암호화/복호화와 같은 데이터 조정도 함께 진행함
- 이를 처리하는 장치로는 코덱이 있으며, 대표 프로토콜로는 ASCII, 유니코드 등이 존재함

> [!Question] 코덱이란?
> 코덱(Codec)은 "**Co**der and **Dec**oder"의 줄임말로, 음성 또는 영상의 신호를 디지털 신호로 변환하는 코더와 그 반대로 변환시켜주는 디코더를 통틀어 부르는 말이다.

### 5계층 - 세션 계층

- 두 응용 시스템 사이의 논리적인 통신을 설정하고 관리하는 계층으로, 동시 송수신 방식 등의 과정을 관리함
- 해당 계층에서는 통신을 시작하고 종료하는 절차 관리, 통신 제어 조정과 같은 부분들의 정의함
	- 통신 제어에는 Simplex, Duplex가 존재하며, 각각 아래와 같음
	- **Simplex(단방향 통신)**
		- 데이터가 한 방향으로만 고정되어 전달되며, 한쪽은 송신만, 다른 쪽은 수신만 함
	- **Duplex(양방향 통신)**
		- 두 장치가 모두 데이터를 송신/수신할 수 있으며 동시에 가능한지에 따라 Half Duplex와 Full Duplex로 구분함
	- **Half Duplex(반이중 통신)**
		- 양방향 통신이 가능하지만, 한 번에 한쪽만 전송하고 번갈아 역할이 바뀌어 전송하게 됨
	- **Full Duplex(전이중 통신)**
		- 양쪽이 동시에 데이터를 보내고 받을 수 있음

### 4계층 - 전송 계층

- 서로 다른 컴퓨터에서 실행 중인 응용 프로세스 사이에 데이터를 전달하는 계층임
- 컴퓨터 내에서 데이터를 받을 프로그램을 포트로 구분하고, 필요한 경우 데이터를 분할하고 복원함
- 대표적인 장치로는 L4 스위치가 있으며, 대표적인 프로토콜로는 `TCP`, `UDP` 등이 존재함
	- TCP는 연결을 설정한 뒤 데이터를 송수신하여, 신뢰성 있는 바이트 스트림을 제공함
	- UDP는 연결 설정 없이 데이터그램을 보내며 자체적인 재전송이나 순서 보장을 제공하지 않음

### 3계층 - 네트워크 계층

- 여러 개의 노드를 거칠 때마다 경로를 찾아주는 역할을 하는 계층으로 데이터를 네트워크들을 통해 전달함
- 데이터를 전달하기 위해 IP 주소로 논리 주소를 지정하고, 목적지로 가기 위한 라우팅, 포워딩 과정을 거침
- 대표적인 장치로는 라우터, L3 스위치가 있으며, 대표적인 프로토콜로는 IP, ICMP, ARP 등이 존재함

## 2계층 - 데이터 링크 계층

- 네트워크 구간에서 데이터에 대해 비트 단위로 신호화/동기화하여 신뢰성있는 전송을 보장하기 위한 계층임
- 주로 상위 계층의 데이터를 프레임으로 감싸고, 프레임을 송수신할 Mac 주소 지정 등의 작업을 진행함

### 1계층 - 물리 계층

- 장치들을 연결하기 위해 필요한 전기적 사항들을 정의하며, 비트를 전기·빛 같은 실제 신호로 전달하고 받음
- 구리 케이블, 광섬유, 무선 전파 등 실제로 데이터를 송수신하는 메개체가 해당 계층에 포함됨
- 비트 정보를 전압, 광 신호, 무선 신호 등으로 표현하고, 수신한 신호에서 비트를 복원함
